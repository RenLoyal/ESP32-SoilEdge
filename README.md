# ESP32-SoilEdge
低成本土壤感知 + 校准 + 边缘预测系统（大二科研训练项目）

## 进度

- [x] **W1**：仓库初始化、RF 基线验证、硬件下单、采集代码骨架
- [ ] **W2**：硬件到齐、接线、空采验证、真实数据采集与建模
- [ ] **W3**：标定实验、模型精度验证
- [ ] **W4**：数据分析、报告撰写

## 硬件
ESP32 + 电容式土壤湿度传感器 v1.2 + DHT22

## 目录
- `hardware/`：Arduino采集代码
- `data/`：原始CSV与标定数据
- `model/`：Python校准与预测脚本
- `figs/`：论文用图
